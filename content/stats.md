Several essays here rest on numbers that go stale within weeks: 

* How many public GitHub commits carry an AI tool's trailer, how many pull requests the review bots touch,
* How many tokens flow through OpenRouter for programming,
* How many sites run React.

My goal with this page is to re-measure those figures at the start of each month and shows each one next to the number as it was written in the essay, so the drift is visible rather than quietly wrong.
